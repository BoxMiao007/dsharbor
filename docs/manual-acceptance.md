# Windows 手动验收手册（真机复核用）

日常界面改动分两档验，都不用打安装包：

1. **量尺寸、看排版**：`pnpm build` 后 `node scripts/mock-preview.mjs`，在普通浏览器里按假数据渲染（最快，但没有原生窗口行为）。
2. **真窗口里点一遍**：`pnpm exec tauri dev`（配合首次的 `pnpm pack:bridge`）。它就是真 WebView2 窗口，改前端存盘即刷新、改 Rust 自动重编重启，拖动 / 缩放 / 贴靠 / 托盘 / 真 DSH 进程都能直接验。**不要**为了验界面去跑 `pnpm exec tauri build` 再装包，那一轮要几分钟。

本手册用于需要**装出来的东西**才能确认的部分——安装器与卸载、注册表与开始菜单、静默安装、开机自启动——逐项走；每步给出「操作」与「期望结果」，不满足时看文末「排查」。

## 0. 构建与产物（Windows 本机）

- 操作：发布验收用性能优先构建——`CARGO_PROFILE_RELEASE_LTO=true CARGO_PROFILE_RELEASE_CODEGEN_UNITS=1 pnpm exec tauri build`（本地快速测试用默认速度优先构建即可，见 README「开发」）。
- 期望：退出码 0；产物 `target/release/bundle/nsis/DSHarbor_<版本>_x64-setup.exe`（2 MiB 量级；打包会连带前端构建；桥接插件 tgz 要先跑 `pnpm pack:bridge` 生成，否则 build script 报 `glob pattern resources/*.tgz path not found`）。

## 1. 安装

- 操作：双击安装包，按中文向导完成（静默安装等价命令：`DSHarbor_<版本>_x64-setup.exe /S`）。
- 期望：装到当前用户目录、无需管理员（安装器默认 `%LOCALAPPDATA%\DSHarbor`；本机实测装在 `D:\Program Files\DSHarbor`，安装器会沿用上次选择的路径）；注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DSHarbor` 中 名称 DSHarbor、版本正确、发布者 BoxMiao007。

## 2. 启动与首次配置

- 操作：从开始菜单打开 DSHarbor（或运行安装目录下的 `dsharbor.exe`，本机为 `D:\Program Files\DSHarbor\dsharbor.exe`）；左栏依次点六个分区看一遍；点左栏底部三颗图标（DSH 官网 / GitHub / 浅暗切换）；最后点「关于」里的两个「打开」。
- 期望：主窗口出现，**没有系统标题栏**，最上面是一条通栏的透明顶栏条（约 40px 高）：左端是加粗的 `DSHarbor` + 紧跟的小字「DSH Web 的桌面壳」（不显示图标），右端是三只窗口按钮 `–` `□` `✕`（15px 见方、1.5px 描边；最大化后中间那只变「还原」；关闭按钮悬停变红，提示「关闭窗口 = 轻量模式：界面内存释放，DSH 与托盘常驻」）。顶栏条与下面的卡片之间留一道窄缝，整页是一组浮在页面背景上的卡片（块与块之间露底，不画通栏分割线）。
- 期望（左栏与工具条）：左栏是一张通高卡片（约 220px 宽），顶部**水平居中**的一句「探索未至之境」（整句加粗），下面一行小字「DeepSeek」（同样居中），再下面一条细线；中部**六项**导航（启动方式 / 环境/插件 / 集成 / 托盘与网络 / 日志 / 关于），未选中项**不画底框**，只有指针悬停或选中时才出现底色（选中项浅蓝底 + 左侧竖条），点一项只换右侧内容，不重建界面、不弹窗，当前分区记在 `localStorage` 键 `dsharbor.ui.panel`，切换后内容回到顶部；底部三颗圆形图标按钮（DeepSeek 官方鲸鱼标 / GitHub 官方 mark / 浅暗切换）各带一圈可辨认的底色与描边（不是裸图标贴在卡片上），两颗外链图标是真正的官方形状、颜色跟随外观（浅色下不是黑块）。右栏最上方是工具条卡片：左边只有三样——「桥接就绪 / 桥接未安装 ⓘ」、「DSH 版本」、「PID —」「监听 —」，**没有「已停止 / 运行中」这类状态徽章**；右边是主操作——停止态只有「启动 DSH」可用，「启动 DSH」右侧紧跟一颗「打开方式」分体按钮（小三角展开三项：应用内打开 / 浏览器打开 / 复制登录链接，选中项行首打勾，**默认「应用内打开」并记住上次选择**，记在 `dsharbor.ui.openMode`；换方式要点三次：展开 → 选 → 点主按钮）；运行中则是「停止 / 重启 DSH / 打开方式」三颗并排。**工具条第 1 颗徽章只有两态**：装过桥接插件显示「桥接就绪」（绿），没装显示「桥接未安装」（灰），读取失败显示「桥接状态读取失败」（红）。三颗主操作按钮的图标段都在**左边**、竖线在图标右侧，文字与图标保持静止（不再有悬停漫过 / 文字被推出去的动效，只剩按下时图标轻微缩一下）；运行中同时出现三颗按钮时仍是一排，左侧徽章不被挤到换行（窗口最窄 900×620 时 PID / 版本徽章自动隐藏，保持一排）。没成功启动过 DSH 时版本徽章显示「DSH 版本未知」。
- 期望（日志）：日志是左栏的**一个普通分区**（第五项，在「托盘与网络」与「关于」之间），点开右侧就是**一张日志大卡**：卡头左边标题「日志」，右边两颗胶囊「清空日志」「复制日志」；下方是一整块**中性色正文框**（深色 `#10161d`、浅色 `#f4f7fb`，1px 描边、14px 圆角、等宽字），撑满剩余高度、自己内部滚。**日志卡只有两层**（大卡 → 正文框），标题与按钮直接在大卡上，不再套一层小卡。**工具条与主卡之间没有窄条、没有浮层、没有遮罩，也没有「点外面收起」这套逻辑了**。**日志只有一个**：DSH 进程输出 + 桥接 / 环境 / npx 缓存等操作输出都进这同一个框，不同批次之间插一行 `--- 时间 ---`；空态显示「（暂无输出）」；**不随切分区清空**，只有点「清空日志」或完全退出程序才清空；**滚到底时自动追新，往上翻的时候不抢滚动**；**产生命令输出的主动操作（启动 / 停止 / 重启 DSH、安装或卸载桥接插件、重装依赖、备份或还原补丁层）不再把界面切走**，改为在左栏「日志」条目右端挂一枚蓝色未读数字，点进「日志」即归零。
- 期望（内容区）：工具条下方是**一张大主卡**，吃掉剩余高度、自己内部整体滚（32px 内边距）。主卡里**每个条目各装一张小卡**（卡中卡，靠明度差区分，卡与卡之间是 20px 露缝、不画分隔线）；需要并排时两小卡之间留 28px 缝。**每张小卡左上角一行标题：15px / 700 字重 / 主文字色**，与卡内 12~13px 的淡色正文明显拉开一档。启动方式 = 启动方式小卡 + 命令预览小卡 + 下方「附加参数 │ 端口」两张并排小卡；**启动方式卡里四个单选项，选中且展开参数的那一项（官方 npx 命令 / 指定程序路径 / 自定义命令）连同下面的参数整组抬一层强调色淡底 + 细描边，参数缩进到选项标题下方；「系统全局命令」没有参数项，选中时只有单选点变蓝、不套底色框**；环境/插件 = **「环境与插件」小卡**（一排环境大按钮 + 右侧一列三颗按钮，从上到下「新建空白环境」「桥接插件」「补丁层」）+ **「插件」小卡**（卡头徽章写「web · 17 个插件」这种「环境名 · 插件数」，列表里每行一个插件，右端是拨动开关、没有「已启用 / 已停用」这类文字）；集成 = 命令行集成小卡 + npx 缓存小卡；托盘与网络 = 「托盘设置 │ 网络与代理」两张并排小卡 + 网络自检小卡；日志 = 一张日志大卡（标题与按钮直接在卡上，正文框是卡里唯一一层，见上一条）；关于 = 只有一张「版本与目录」小卡（壳版本 / DSH 版本 / 开源许可证 / 配置目录 / 日志目录，两个目录条目右侧各有「打开」）。仓库与官网入口只在左栏底部，关于分区里不再重复。
- 期望（下拉弹层与滚动）：所有下拉框都用自绘弹层（12px 圆角、卡片底色 `var(--card)`、带投影、无毛玻璃，已选中项行首带 ✓；静止时蓝底落在当前值那一行，指针一进列表或按上下键蓝底只跟光标走，Esc / 上下方向键 / 回车可用）；**弹层不会被主卡裁掉**——按可视高度自动向上翻转并压缩高度（实测最小窗 900×620 下打开「运行环境」弹层完整可见）。**只有主卡内部滚**（左栏与工具条固定，页面本身不滚）；内容区右缘浮出一条 5px 淡色胶囊指示位置，换分区后按新内容重算高度。
- 期望（外观与其它）：左栏底部那颗太阳 / 月亮切浅色 / 深色——只换配色不重建界面（分区、输入框内容、滚动位置都不丢），选择记在 `localStorage` 键 `dsharbor.ui.theme`（`light` / `dark`）并镜像进 `config.json` 的 `uiTheme`，壳重启后沿用；旧版本的 `classic` 读作浅色、`nativeDark` / `native` 读作深色。工具条第 1 颗徽章里的 ⓘ 悬停或聚焦才有气泡说明（不占布局）；登录失败时才在工具条下方显示原因原文。全页徽章统一大小：高度 24px、水平内边距 10px、字号 13px。壳重启前曾成功启动过 DSH 的，本次打开界面后版本徽章直接显示上次记下的版本号（见第 6 步）。

## 3. 启动 DSH 并取登录链接

- 操作：点「启动 DSH」（首次会自动下载 npx 包，稍慢）。
- 期望：主按钮立刻从蓝色「启动 DSH」变成红色「停止」并多出「重启 DSH」，几秒后出现 PID 与端口（**运行状态只看这颗按钮，工具条里没有状态徽章**）；**版本徽章在几秒内从「DSH 版本未知」变为实际版本（如 `DSH v0.2.0-rc.2`，四个启动方式都要能读到；WSL 模式下不应把发行版欢迎语误当版本号）**；**点「启动 DSH」（或「停止」/「重启 DSH」）后界面留在当前分区不动，日志里追加一段带 `--- 时间 ---` 的启动输出，左栏「日志」条目右端出现蓝色未读数字（当时就停在「日志」分区的话不出数字，正文直接跟着追到底）**（启动后同一个按钮的文案变成「停止」，点它就是停止；停止后回到「启动 DSH」）；工具条第 1 颗徽章（桥接状态）在装过桥接插件时是「桥接就绪」、没装时是「桥接未安装」，拿到登录链接与它无关；**不会弹出系统浏览器**（壳自动追加 `--no-open`；界面用「应用内打开」在壳窗口查看，或点「浏览器打开」显式交给系统浏览器）。失败时显示含退出代码与最近输出的提示，并给出诊断日志路径线索（`~/.dsh/logs/startup-*.log`）。**按钮动效**：指针停在「启动 DSH」上时文案逐字翻成「开始运行」、按钮轻微抖动（±0.5px、0.2s 一轮）；运行中把指针停到「停止」上按钮是红色、停到「重启 DSH」上是琥珀色 `#f5ae51`（该按钮上的字转深色 `#1b2536`），按下时图标缩一下；**没有悬停漫过 / 文字被推出去的动效**（那是上一版被去掉的）；图标段在左、竖线在图标右侧，文字始终单行不换行。

## 4. 两种打开方式与窗口独立性

- 操作：点「打开方式」右边小三角选「应用内打开」→ 点主按钮；再展开选「浏览器打开」→ 点主按钮；再展开选「复制登录链接」→ 点主按钮（粘贴到记事本验证）；然后先关 DSH 窗口（观察主窗口是否还在），再关主窗口（观察 DSH 窗口是否还在）。
- 期望：「应用内打开」弹出的 DSH 窗口**已是登录态**（不需要手工拼接 token 链接），标题为 DeepSeek Harness；DSH 窗口尺寸随主显示器自适应（高度不越出屏幕下边界）「浏览器打开」在系统默认浏览器打开同一界面；「复制登录链接」把带 token 的完整链接写进剪贴板、按钮短暂变「已复制链接」，DSH 未就绪时主按钮与三角都是禁用态；**两个窗口相互独立**——关 DSH 窗口后主窗口仍在；关主窗口后 DSH 窗口仍在（DSH 后端与托盘常驻），托盘「打开启动界面」可随时找回主窗口。

## 5. 轻量模式循环（3~5 轮）

- 操作：右键托盘确认菜单六档齐全（**浏览器打开 / 应用内打开 / 打开启动界面 / 重启 DSH / 停止 DSH / 完全退出**）→ 关闭主窗口 → 任务管理器观察内存 → 单击托盘图标（默认打开启动界面；Win11 图标可能收在「隐藏的图标」小箭头里）。
- 期望：关窗后壳进程与 DSH 后端仍存活，界面内存明显下降（参考量级：两窗全开约 1037 MB → 关窗约 474 MB）；单击托盘后窗口原地重建，仍为「运行中」且登录链接就绪；重复多轮无白屏。在界面把「托盘单击打开」改为「应用内窗口」后，单击托盘应直接打开 DSH 窗口（未就绪时回退启动界面）。

## 6. 重启与完全退出

- 操作：界面「重启 DSH」（运行中一键重启）；再托盘「重启 DSH」；再托盘「停止 DSH」；然后界面点「重启 DSH」重新拉起，最后托盘「完全退出」。
- 期望：重启后 DSH 的 PID 更换、登录链接重新就绪、窗口内容可用；**托盘「完全退出」后重新打开 DSHarbor，状态行里的版本徽章仍显示上次记录的版本号（不是「DSH 版本未知」；值存在 `%APPDATA%\DSHarbor\dsh-version.txt`），点「启动 DSH」后按原规则重新查询并刷新**；「停止 DSH」后状态回「已停止」、PID/端口清空、`netstat` 无 3080 LISTENING，但**壳与窗口仍在**；完全退出后壳与 DSH 进程全部消失，`netstat -ano | findstr "3080"` 无 LISTENING 残留。

## 7. 意外退出恢复

- 操作：启动 DSH 后，在任务管理器结束其 node 进程（或 `taskkill /PID <会话PID> /T /F`，会话 PID 见界面）。
- 期望：1~3 秒内界面显示「启动失败」与线索文案，**此时合并按钮已回到「启动 DSH」（子进程已退出，点它就是重新启动）**；点「重启 DSH」后恢复「运行中」，链接就绪。

## 8. 单实例

- 操作：壳已打开时再次启动 DSHarbor（分别测：窗口在时 / 轻量态关窗后）。
- 期望：不出现第二个壳进程；窗口在时聚焦已有窗口；轻量态时自动重建窗口。

## 9. 配置持久化与端口覆盖

- 操作：改「启动方式/附加参数/端口」等项目 → 关闭壳 → 重开。
- 期望：刚才的配置原样恢复（`%APPDATA%\DSHarbor\config.json`）；端口填自定义值后启动，DSH 实际监听在该端口（界面与 `netstat` 一致）；填非法值（如 70000）点启动：明确报错、不启动、配置不落盘。

## 10. 桥接插件安装 / 卸载 / 回滚

- 操作：停掉 DSH → 左栏「环境/插件」→ 环境大按钮行末的「桥接插件」（弹出浮窗）→「安装桥接插件」（点按钮后界面留在「环境/插件」分区，左栏「日志」上出现蓝色未读数字，点进去能看到 pnpm/命令输出）；再测「卸载」；「恢复最近备份」；最后点「打开备份目录」；按 Esc 或点浮窗右上角 ✕ 关闭。
- 期望：安装/卸载退出码 0 且提示「已登记/已摘除 dsh.profile.bundles」；**桥接恒装在启动用的 web 环境**（浮窗里「目标环境」一行显示的就是它，与上方选中的管理环境无关）；安装后工具条第 1 颗徽章变「桥接就绪」，卸载后变「桥接未安装」；恢复备份后 profile 文件与安装前逐字节一致（哈希清单在备份目录 manifest.txt）；**连做 6 次以上安装/卸载后，`%APPDATA%\DSHarbor\backups` 里只留最近 5 个 `backup-*` 目录，且被删掉的旧备份名以「旧备份清理」一行出现在统一日志里**；**点「打开备份目录」用资源管理器打开 `%APPDATA%\DSHarbor\backups`（目录不存在时先建出来），面板内提示「已在资源管理器中打开备份目录：<路径>」**；**四个按钮（安装桥接插件 / 卸载 / 恢复最近备份 / 打开备份目录）在浮窗正文里从左往右排（安装桥接插件在最左）；浮窗按内容收高度、正中间弹出，带半透明遮罩，遮罩挡住下方主卡且不可点击穿透**。

## 11. 卸载与数据保留

- 操作：Windows 设置 → 应用 → DSHarbor → 卸载（静默：安装目录下的 `uninstall.exe /S`；默认当前用户目录，若安装时改过路径以实际安装目录为准）。
- 期望：仅删除安装目录；`%USERPROFILE%\.dsh`（DSH 数据）与 `%APPDATA%\DSHarbor`（壳配置、DSH 版本号记录与桥接备份）完整保留。

## 12. 无边框窗口交互

- 操作：按住顶栏条的空白处拖动窗口 → 再按住顶栏里的 `DSHarbor` 文字拖动 → 双击顶栏空白处 → 拖窗口四边与四角 → 把窗口往窄了拖到最窄（应停在 900×620）→ 把鼠标移到右上角「关闭」按钮上 → 拖到屏幕左 / 右边缘（Windows 11 贴靠）。
- 期望：窗口没有系统标题栏，顶部是一条**通栏的透明顶栏条**（约 40px 高、无底色）：左端是加粗的 `DSHarbor` 紧跟小字「DSH Web 的桌面壳」，右端是三只窗口按钮；顶栏条下才是左栏卡片与右栏卡片。三只按钮都是内联 SVG `–` `□` `✕`（15px 见方、1.5px 描边，等大等重；最大化后中间那只变「还原」`⧉`；关闭按钮悬停变红，提示文案说明 `✕` 即轻量模式）；**浅/深切换在左栏底部，不在窗口按钮里**；按住顶栏条的任何位置（包括 `DSHarbor` 文字与副标题）都能拖动整个窗口，按住卡片内部则不动窗口；双击顶栏空白处 = 最大化 / 还原；窗口四边与四角可拖动缩放（Tauri 2 无边框窗口的原生缩放），**默认 1240×800、最小 900×620**；**Windows 11 的贴靠布局（悬停最大化按钮弹出的布局菜单）与 `Alt+Space` 系统菜单不可用**——无边框窗口的已知取舍（见 `docs/decisions.md`）。
- 期望（滚动条）：页面本身**不滚**（整页定高，只有主卡内部滚，左栏与工具条固定）；主卡超出时右缘浮出一条 5px 淡色细胶囊指示位置（滚动时或指针落在那条带上才出现，约 1 秒后淡出，按住可上下拖）；**换分区后内容回到顶部、胶囊高度按新内容的可滚距离重算**。
- 期望（托盘重开，回归检查）：关掉启动界面（轻量模式）后，从托盘单击或再双击一次 exe 重开窗口——**只应有一组窗口按钮，不得出现系统标题栏叠在上面**；重建出的窗口仍是 1240×800（最小 900×620），且仍停在上次选的分区、沿用上次的浅/深配色与打开方式。
- 期望（下拉弹层不被裁）：在主卡里**滚到最底部**，点最下面那个下拉框——弹层应完整可见（主卡是滚动容器，会裁掉溢出的绝对定位元素，所以弹层按可视高度自动向上翻转并压缩高度），不得只露出上半截；窗口拖到最小 900×620 再重复一次，结论相同。

## 13. 轻量模式延迟进入

- 操作：在「托盘与网络」分区的「托盘设置」块里把「关闭窗口后释放界面内存」设为「30 秒」→ 关闭主窗口 → 30 秒内单击托盘图标（或再双击一次 DSHarbor.exe）→ 再关窗、等满 30 秒后单击托盘 → 把设置改回「立即」再关窗 → 重启壳。
- 期望：关窗后窗口立刻消失、托盘仍在、DSH 后端不中断；30 秒内点托盘图标，窗口**秒回**且仍是原来的界面（不重新加载 DSH）；第二次等满 30 秒后再点，打开的是**新建窗口**（会重新加载 DSH）；改回「立即」后关窗即销毁，与旧版一致；重启壳后设置仍是上次选的值。

## 14. 界面文案改名

- 操作：看界面里「打开方式」主按钮上的默认文案与托盘右键菜单，再看「托盘与网络」分区「托盘单击打开」下拉里的选项。
- 期望：按钮与托盘右键菜单里都是「应用内打开」；「托盘单击打开」下拉里那项是「应用内窗口」。

## 15. DSH 窗口里的链接

- 操作：在「应用内窗口」的 DSH 页面里点一个站外链接（如官网 / 文档），再点一个站内跳转，最后点一个 `target="_blank"` 的链接。
- 期望：站外链接交给系统默认浏览器打开、DSH 窗口原地不动；站内跳转仍在窗口里完成；`target="_blank"`（新开标签）的链接同样进浏览器，DSH 窗口不弹空白页。

## 16. 分区切换与悬停回归

- 操作：依次点左栏六项；把指针移到每个图标上、再移开；在长内容（启动方式 / 环境/插件）里滚到底再切分区；点左栏底部切一次浅色再切回深色。
- 期望：点图标只换右侧内容，图标本身不位移（没有「悬停展开成图标＋文字」那种位移），选中项是浅蓝底 + 左侧 3px 竖条；悬停只是底色变浅；分区内容互不串（切回时内容列表与上次一致、滚动回顶部）；浅/深切换不重建界面（输入框里的字、选中的下拉值、滚到哪都不丢）；整页背景不随内容滚动而变化。

## 排查

- **打开只有一个「无法访问此页面 / 127.0.0.1 拒绝连接（ERR_CONNECTION_REFUSED）」的错误页，而且窗口没有关闭按钮**：安装目录里的 exe 是裸 `cargo build` 编出来的开发版——没开 tauri 的 `custom-protocol`，前端没嵌进去，它按 `devUrl` 去连 `http://127.0.0.1:1420` 的 Vite dev server。主窗口是无边框的（`decorations: false`），页面没渲染出来就没有自绘标题栏、也就没有关闭按钮。退出方式：`Alt+F4`、任务栏图标右键「关闭窗口」，或托盘图标右键「完全退出」。修复：用 `pnpm exec tauri build` 出的安装包重装（安装目录里那份安装包也可以 `<setup>.exe /S` 静默重装）；不要用裸构建的 `target/release/dsharbor.exe` 去替换安装目录。
- **端口被占用（EADDRINUSE）**：profile 里 webserver 端口被别的程序占用（注意 WSL 镜像网络下 Windows/WSL 共用 localhost 端口，刚停过 DSH 时等 1~2 分钟 TIME_WAIT 消散）。改「端口」字段用自定义端口，或释放占用。
- **桥接未启用**：DSH 启动时没带 nonce（例如你自己在终端跑 `dsh web`），属预期降级；此时工具条第 1 颗徽章显示「桥接未安装」，登录链接改由日志解析取得。
- **WSL 插件安装报 pnpm 错误**：确认壳运行时已注入清洗后的 PATH（4.0 起内置）；发行版内 pnpm 版本冲突时 `npx @deepseek-ai/dsh plugin --profile web …` 手动复核。
- **「安装桥接插件」报 `ERR_PNPM_PACKAGE_MANAGER_ADD_RESOLVE_LATEST`（v0.1.0 实机缺陷，已修）**：安装目录含空格（本机为 `D:\Program Files\DSHarbor`）时，pnpm 会把 `file:` 规格在空格处截断后当包名去 registry 查。现在壳会先把插件包暂存到无空格目录（`%APPDATA%\DSHarbor\cache`，WSL 侧为 `/tmp/dsharbor-bridge`）再安装；若仍报错，检查暂存目录与 `TEMP` 是否都含空格。
- **看不到托盘图标**：Win11 默认折叠，拖到任务栏常显或点「隐藏的图标」。
