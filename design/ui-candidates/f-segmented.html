启动方式

未全局安装 DSH 时用；首次启动会自动下载（较慢）。执行 npx --yes @deepseek-ai/dsh web --no-open

已执行过 npm install -g @deepseek-ai/dsh，直接调系统里的 dsh。

最可靠：直接启动 dsh.exe / dsh.cmd 的完整路径，不走 PATH。

Windows 壳启动 WSL 发行版里的 DSH，需要该发行版里已装好 DSH。
