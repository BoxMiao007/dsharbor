界面候选（5 套）

五套都是可点的静态稿：假数据完全一样（运行中 · 桥接就绪 · npx 启动），所以横向比的只有布局与风格本身。点开任意一套，窗口大小按卡片上标的调一下再看，最贴近正式窗口时的样子。

先看基线：当前线上界面（正式界面 + 假数据，用于对照）。若打不开，先在仓库里跑一次 node scripts/mock-preview.mjs --no-serve。

最省像素、最像开发者工具，参数与命令一目了然；第一次用的人可能觉得字多。

980 × 740最紧凑

挑的时候可以看这几点

  • 窗口大小：你平时会把它开多大？A / C 需要宽一点，D / E 窄一点也好看。
  • 第一眼：打开界面最想知道的是「DSH 跑起来没有、链接能不能点」，哪一套更快回答这个问题。
  • 日常动作：复制登录链接、打开界面、停 / 重启、装桥接插件——哪一套里这些最好找。
  • 深色还是浅色：A 沿用现在的雾光蓝，C 更中性，D 是浅色，E 是纯黑。
  • 要不要左侧导航：以后再加设置项时，B 和 D 最不容易变乱。

这五套都是静态稿，只用来比较布局和风格；选定之后再按它把真实界面重做一遍（真实交互、真实数据都在正式实现里做）。
